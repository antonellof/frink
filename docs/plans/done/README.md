# Finished plans

A plan moves here when every todo in its frontmatter is `completed`.

They are kept rather than deleted because the todo text is where the
measurements live: what was tried, what the numbers were, what was
refused and why. That is the part worth reading a year later, and it is
not recoverable from the diff.

Not every plan here carries frontmatter todos -- some state their
status in prose -- so "all completed" is read from whichever the file
uses.
